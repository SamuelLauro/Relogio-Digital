# 📚 Estudo: relógio digital

Relógio digital com data por extenso, em HTML, CSS e JavaScript. Feito entre março e maio de 2023 para praticar o objeto `Date` e atualizações periódicas com `setInterval`.

**Demo:** https://samuellauro.github.io/estudo-relogio-digital/

## O que pratiquei

- `Date` e `toLocaleString('pt-BR')` para mostrar o dia da semana e o mês por extenso.
- Formatar horas com dois dígitos.
- Atualizar a página a cada segundo com `setInterval`.
